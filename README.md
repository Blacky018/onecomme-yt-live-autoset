# YouTube 配信 URL 自動セット（わんコメ用プラグイン・非公式）

YouTube で配信を始めると、わんコメの YouTube 枠の URL を「今配信している枠」に自動で書き換えるプラグインです。配信のたびに URL をコピーして貼り替える手間がなくなります。

> **非公式のプラグインです。** わんコメ（OneComme）・YouTube・Google とは関係ありません。各社へのお問い合わせはご遠慮ください。

## できること

- 30 秒おき（変更可）に、自分のチャンネルの配信中の枠を探します
- 配信前でも、開始予定が近い予約枠を先にセットしておきます（配信が始まった瞬間からコメントを読めます。待機所のコメントも取れます）
- 見つかったら、わんコメの YouTube 枠の URL を `https://www.youtube.com/watch?v=<動画ID>` に書き換えます
- 枠が接続中なら、自動でつなぎ直します
- 配信中の枠があれば、予約枠より常にそちらを優先します

### なぜ必要？

わんコメにチャンネルの `/live` URL を入れておく方法もありますが、

- 公開の予約枠があると、YouTube が予約枠のほうを返してしまう
- わんコメで `/live` URL を使うと、チャット欄を読み込めないことがある

という理由で、配信ごとの URL（`watch?v=...`）を入れるのが確実です。このプラグインはそれを自動で行います。

## 必要なもの

- わんコメ 5.2 以上（Windows）
- Google アカウント（配信しているチャンネルのもの）
- Google Cloud のプロジェクト（無料。下の手順で作ります）

## 配信の探し方（2 種類）

| | Google ログイン（おすすめ） | API キー |
|---|---|---|
| 見つけられる配信 | 自分の配信すべて（公開・限定公開・非公開・メン限） | 公開の配信のみ |
| 準備 | OAuth クライアントを作ってログイン | API キーを作る |
| 確認間隔の下限 | 30 秒 | 60 秒 |
| YouTube API の使用量（下限の間隔で確認したとき・最大） | 1 日 5,760 | 1 日 2,880 |

YouTube API は 1 日 10,000 まで無料で使えます。どちらの方式も範囲内です。

## インストール

1. 配布 zip を展開します
2. 中の `yt-live-autoset` フォルダを、わんコメのプラグインフォルダに入れます
   - エクスプローラーのアドレス欄に `%APPDATA%\onecomme\plugins` と入力すると開けます
3. わんコメを起動（起動中なら再起動）し、「プラグイン」画面で「YouTube 配信 URL 自動セット（非公式）」を有効にします
4. 設定画面を開きます: <http://localhost:11180/plugins/com.riito.yt-live-autoset/index.html>

**更新するとき**は、新しい `yt-live-autoset` フォルダで上書きしてください。設定（`state.json`）はそのまま残ります。

## 準備 1: Google Cloud のプロジェクトと YouTube Data API

1. [Google Cloud コンソール](https://console.cloud.google.com/) を開き、新しいプロジェクトを作ります
2. 「API とサービス」→「ライブラリ」で **YouTube Data API v3** を探して「有効にする」を押します

## 準備 2-A: Google ログイン方式（おすすめ）

### OAuth クライアントを作る

1. 「API とサービス」→「OAuth 同意画面」（「Google Auth Platform」と表示されることもあります）を開き、「開始」を押します
   - アプリ名: 自由（例: わんコメ配信セット）
   - サポートメール・連絡先: 自分のメールアドレス
   - 対象: **外部**
2. 「対象」の画面で、公開ステータスを **「アプリを公開」→「本番環境」** にします
   - **「テスト」のままだと、ログインが 7 日で切れます**
   - 自分だけで使う場合、Google の審査は必要ありません
3. 「クライアント」→「クライアントを作成」→ アプリケーションの種類 **「デスクトップ アプリ」** → 作成
4. 表示された **クライアント ID** と **クライアント シークレット** を控えます

### プラグインでログインする

1. 設定画面の「配信の探し方」で **Google ログイン** を選びます
2. クライアント ID とシークレットを貼り、「書き換えるわんコメの枠」で YouTube の枠を選んで **保存** します
3. **Google でログイン** を押し、配信しているチャンネルのアカウントを選びます
4. 「Google はこのアプリを確認していません」と出たら、「詳細」→「（アプリ名）（安全ではないページ）に移動」→「続行」を押します
   - 自分で作ったアプリなので問題ありません
   - 求める許可は「YouTube アカウントの表示」（読み取り専用）だけです
5. 「ログインしました」と出たらタブを閉じます。設定画面が「ログイン済み」になれば完了です

## 準備 2-B: API キー方式

1. 「API とサービス」→「認証情報」→「認証情報を作成」→「API キー」
2. 作ったキーの「API の制限」で **YouTube Data API v3** だけを選んで保存します（おすすめ）
3. 設定画面で **API キー** 方式を選び、API キー・チャンネル（`@ハンドル` かチャンネル URL）・書き換える枠を入れて **保存** します

## 使い方

設定が終わったら、あとは YouTube で配信を始めるだけです。

- **予約枠から配信する場合**: 開始予定の 24 時間前から、その枠がわんコメに先にセットされます。配信を始めた瞬間からコメントを読めます
- **予約なしで「今すぐ配信」する場合**: 配信開始から 30 秒〜1 分ほどで切り替わります（YouTube が配信開始を反映するまでの時間＋確認間隔）
- 急ぐときは設定画面の **今すぐ確認** を押してください

予約枠の先取りが要らない場合は、設定画面の「配信前に予約枠を先にセットする」をオフにしてください。使わない予約枠を残していると、その枠が先にセットされることがあります（本当の配信が始まれば、そちらに自動で切り替わります）。

設定画面の上部に、今の状態が表示されます。

| 表示 | 意味 |
|---|---|
| 待機中 | 配信中の枠がありません（配信開始を待っています） |
| セット済み | 配信中の枠がわんコメにセットされています |
| セット済み（予約枠） | 配信開始前の予約枠を先にセットしています |
| 設定が必要 | 足りない設定があります（メッセージを見てください） |
| エラー | 問題が起きています（メッセージを見てください）。失敗が続くと確認の間隔を延ばします |

## うまくいかないとき

| 症状 | 確認すること |
|---|---|
| 「待機中」のまま | API キー方式なら、配信が**公開**になっているか（限定公開・メン限は Google ログイン方式が必要）。予約枠は開始予定の 24 時間前にならないと先取りされません |
| 「Google のログインが切れました」 | OAuth 同意画面が「本番環境」になっているか確認し、もう一度「Google でログイン」 |
| 「API キーが正しくありません」 | キーのコピーミス・「API の制限」の設定 |
| 「YouTube Data API v3 が有効になっていません」 | 準備 1 の 2 番 |
| 「1 日の利用上限に達しました」 | 確認の間隔を長くする。上限は毎日リセットされます（太平洋時間の 0 時） |
| 「YouTube の枠ではないため書き換えません」 | 書き換える枠に、YouTube 以外（ツイキャスなど）の枠を選んでいないか |
| 「チャットは現在ご利用いただけません」と出る | 配信が**非公開**になっていないか（非公開の配信は YouTube 側でチャットが使えません）。限定公開か公開に変えてから、わんコメの枠の接続を一度オフ→オン。「今すぐ配信」は前回の公開設定を引き継ぐことがあるので、配信前に確認してください |
| セットされたのにコメントが流れない | わんコメの枠の接続を一度オフ→オンにする |

プラグインの動作ログは、わんコメのログフォルダの `plugin.log` に出ます（API キーやトークンは書き出しません）。

## 保存するデータと通信先

このプラグインは、利用者の情報を作者や第三者に送りません。

- **保存するもの**（`%APPDATA%\onecomme\plugins\yt-live-autoset\state.json`）: 設定画面で入れた値と、Google ログインで得たトークン
  - API キー・シークレット・トークンは**暗号化されずに**保存されます。このファイルを人に渡したり、共有フォルダに置いたりしないでください
- **通信先**:
  - `www.googleapis.com`（YouTube Data API。配信中の枠を探す）
  - `oauth2.googleapis.com` / `accounts.google.com`（Google ログイン）
  - `127.0.0.1:11180`（わんコメ本体の API。枠の URL を書き換える）
  - ログインの間だけ、`127.0.0.1` の一時的なポートで Google からの戻りを受け取ります

### YouTube API サービスについて

このプラグインは YouTube API サービスを使います。使用にあたっては [YouTube 利用規約](https://www.youtube.com/t/terms) と [Google プライバシー ポリシー](https://policies.google.com/privacy) が適用されます。

### 許可を取り消す・アンインストールする

1. 設定画面の **ログアウト** を押します（Google 側の許可も取り消します）
   - [Google アカウントの「サードパーティ製のアプリとサービス」](https://myaccount.google.com/connections) からも取り消せます
2. わんコメでプラグインを無効にし、`%APPDATA%\onecomme\plugins\yt-live-autoset` フォルダを削除します
3. 不要になった API キー・OAuth クライアントは、Google Cloud コンソールで削除してください
