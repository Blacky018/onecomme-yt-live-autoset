開始予定が近い予約枠（12 時間前〜24 時間後）を、配信開始前にセットしておきます。配信が始まるとすぐコメントを読めて、待機所のコメントも取れます。配信中の枠があればそちらが優先です。

Google ログインは 30 秒以上、API キーは 60 秒以上（短く入れても下限で確認します）。YouTube API の 1 日の上限 10,000 に対し、Google ログインを 30 秒ごとにすると最大 5,760、API キーを 60 秒ごとにすると 2,880 使います。

API キー方式は公開の配信のみ対象です。限定公開・メン限は Google ログイン方式を使ってください。
