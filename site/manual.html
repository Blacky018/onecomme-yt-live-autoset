設定マニュアル

配信枠オートセット（わんコメ用プラグイン・非公式）

インストールから、配信を始めたら自動でわんコメにつながるようになるまでの手順です。はじめての方で 20〜30 分ほどかかります。設定は最初の 1 回だけで、あとは配信を始めるだけで動きます。

全体の流れ

  1. プラグインをわんコメに入れる（5 分）
  2. Google Cloud でプロジェクトを作る（5 分）
  3. ログイン用の設定をする（10 分）
  4. クライアント ID を作る（3 分）
  5. プラグインに入力してログインする（5 分）
  6. 配信する

用意するもの

  • わんコメ 5.2 以上（Windows）
  • 配信しているチャンネルの Google アカウント
  • プラグインの zip（ダウンロードページ、または BOOTH）

Google Cloud は Google のサービスを使うための管理画面です。このプラグインの使い方なら無料で、クレジットカードの登録も要りません。

1. プラグインをわんコメに入れる

  1. ダウンロードした zip を右クリックして「すべて展開」を押します。
  2. わんコメの「プラグイン」画面を開き、「プラグインフォルダ」ボタンを押します。フォルダが開きます。
  3. 展開したフォルダの中の yt-live-autoset フォルダを、開いたプラグインフォルダにドラッグして入れます。
  4. わんコメの「プラグイン」画面で「再読み込み」を押し、「配信枠オートセット（非公式）」を有効にします。

よくある間違い: yt-live-autoset-0.5.1 のような外側のフォルダごと入れると動きません。プラグインフォルダを開いたとき、yt-live-autoset の中にすぐ plugin.js がある形が正解です。

2. Google Cloud でプロジェクトを作る

ここからは、配信しているチャンネルの Google アカウントでログインした状態で進めます。

  1. Google Cloud の「新しいプロジェクト」画面を開きます。はじめて使う場合は、利用規約への同意を求められるので、内容を確認して同意します。
  2. 「プロジェクト名」に分かりやすい名前（例: haishinwaku-autoset）を入れて「作成」を押します。
  3. 画面の左上（Google Cloud のロゴの横）に、作ったプロジェクトの名前が出ていることを確認します。出ていなければ、そこを押してプロジェクトを選びます。

作成のあとに「権限が拒否されました」と出ることがあります。プロジェクトはできているので、左上でプロジェクトを選び直せば先に進めます。

YouTube Data API を有効にする

  1. YouTube Data API v3 のページを開きます（左上が作ったプロジェクトになっているか確認）。
  2. 「有効にする」を押します。画面が切り替われば完了です。

3. ログイン用の設定をする

プラグインが「あなたの YouTube の配信一覧を見る」ための設定です。

3-1. アプリの情報を入れる

  1. Google Auth Platform を開き、「開始」を押します。
  2. アプリ情報
    • アプリ名: 配信枠オートセット（好きな名前で OK。ログイン画面に表示されます。「YouTube」「Google」という言葉は入れられません）
    • ユーザー サポートメール: 自分のメールアドレスを選ぶ
    「次へ」を押します。
  3. 対象: 「外部」を選んで「次へ」。
  4. 連絡先情報: 自分のメールアドレスを入れて「次へ」。
  5. 終了: 「Google API サービスのユーザーデータに関するポリシー」を確認してチェックを入れ、「続行」→「作成」を押します。

3-2. ホームページとプライバシーポリシーを入れる

  1. 左のメニューの「ブランディング」を開きます。
  2. 「アプリのドメイン」に次の 2 つを貼り付けます。
    アプリケーションのホームページhttps://blacky018.github.io/onecomme-yt-live-autoset/
    アプリケーション プライバシー ポリシー リンクhttps://blacky018.github.io/onecomme-yt-live-autoset/privacy.html
  3. 「承認済みドメイン」の「ドメインの追加」を押し、blacky018.github.io を入れます。
  4. 一番下の「保存」を押します。

ロゴは入れないでください。入れると Google の審査が必要になり、審査が終わるまでログインできなくなります。

3-3. 本番環境にする（大事）

  1. 左のメニューの「対象」を開きます。
  2. 公開ステータスの「アプリを公開」を押し、確認画面で「確認」を押します。
  3. 公開ステータスが「本番環境」になれば完了です。

必ずログインする前に本番環境にしてください。「テスト中」のままログインすると、7 日でログインが切れます。あとから本番環境にしても、テスト中にしたログインは 7 日で切れるので、そのときはもう一度ログインし直してください。

自分だけで使うアプリなので、Google の審査（確認）を受ける必要はありません。

4. クライアント ID を作る

  1. 左のメニューの「クライアント」を開き、「クライアントを作成」を押します。
  2. アプリケーションの種類: 「デスクトップ アプリ」を選びます。
  3. 名前: 分かりやすい名前（例: わんコメ 配信枠オートセット）。「このクライアントを AI 対応エージェントに使用する」にはチェックを入れません。
  4. 「作成」を押すと、クライアント ID と クライアント シークレット が表示されます。「JSON をダウンロード」で控えておくと安心です。

クライアント シークレットは人に見せないでください。スクリーンショットを送るとき、配信画面に映すときも注意してください。

5. プラグインに入力してログインする

  1. わんコメの「プラグイン」画面の一覧で、このプラグインの URL をクリックすると、設定画面がブラウザで開きます。
    （直接開く場合: http://localhost:11180/plugins/com.riito.yt-live-autoset/index.html。わんコメを起動している PC で開いてください）
  2. 「配信の探し方」で「Google ログイン」を選びます。
  3. 「OAuth クライアント ID」と「OAuth クライアント シークレット」に、4 で表示されたものを貼り付けます。
  4. 「書き換えるわんコメの枠」で、わんコメに登録してある YouTube の枠を選びます。出てこないときは「一覧を更新」を押してください。
    わんコメに YouTube の枠がまだない場合は、先にわんコメで YouTube の枠を 1 つ追加しておきます（URL は何でも OK。プラグインが書き換えます）。
  5. 「保存」を押します。
  6. 「Google でログイン」を押し、配信しているチャンネルのアカウントを選びます。
  7. 「このアプリは Google で確認されていません」と出たら、左下の「詳細」→「配信枠オートセット（安全ではないページ）に移動」を押します。
    自分で作ったアプリなので問題ありません。求める許可は「YouTube アカウントの表示」（読み取り専用）だけです。
  8. 許可の画面で「続行」を押し、「ログインしました」と出たらそのタブを閉じます。
  9. 設定画面の上の状態が「待機中」や「セット済み」になれば完了です。

そのほかの設定

配信前に予約枠を先にセットするオンにすると、開始予定の 24 時間前から予約枠をわんコメにセットします。待機所のコメントも取れます（おすすめ: オン）
配信が始まったら、わんコメの接続を自動でオン（つなぎ直し）にするオンにすると、配信開始時にわんコメの接続を自動でオンにします。接続中ならつなぎ直します（おすすめ: オン）
確認する間隔（秒）配信を探す間隔です。初期値の 30 秒のままで大丈夫です

6. 配信する

設定が終わったら、わんコメを起動しておき、YouTube で配信を始めるだけです。

  • 予約枠から配信する場合: 開始予定の 24 時間前から、その枠がわんコメにセットされます。配信が始まると、30 秒ほどでわんコメの接続がオンになります。
  • 予約なしで「今すぐ配信」する場合: 配信開始から 30 秒〜1 分ほどで、わんコメの枠が切り替わって接続されます。
  • 急ぐときは、設定画面の「今すぐ確認」を押してください。

状態の見方（設定画面の上）

待機中配信中・まもなく始まる予約枠がありません
セット済み配信中の枠がわんコメにセットされています
セット済み（予約枠）配信開始前の予約枠を先にセットしています
設定が必要足りない設定があります（メッセージを見てください）
エラー問題が起きています（メッセージを見てください）

わんコメを無料版で使っている場合は、配信の概要欄などに、わんコメのクレジット（例: 配信者のためのコメントアプリ「わんコメ」https://onecomme.com）を書いてください。詳しくはわんコメの利用規約をご覧ください。

更新するとき

新しい zip の yt-live-autoset フォルダで、プラグインフォルダの中の同じフォルダを上書きし、わんコメの「再読み込み」を押します。設定とログインはそのまま残ります。

うまくいかないとき

サポート・よくある質問をご覧ください。解決しないときの送り先（フォーム）もあります。

API キー方式で使いたい（Google ログインを使わない）

公開の配信だけでよければ、Google ログインの代わりに API キーでも使えます（限定公開・メンバー限定の配信は見つけられません）。2 の手順のあと、Google Cloud の「API とサービス」→「認証情報」→「認証情報を作成」→「API キー」でキーを作り、プラグインの設定画面で「API キー」方式を選んで、キーとチャンネル（@ハンドル かチャンネル URL）を入れて保存します。キーには「API の制限」で YouTube Data API v3 だけを許可しておくのがおすすめです。
