YouTube 配信 URL 自動セット（わんコメ用プラグイン・非公式）
制定日: 2026 年 10 月 28 日

このページでは、わんコメ用プラグイン「YouTube 配信 URL 自動セット」（以下「本プラグイン」）が扱う情報について説明します。本プラグインは利用者の PC の中だけで動きます。作者が運営するサーバーはなく、作者が利用者の情報を受け取ることはありません。

1. 本プラグインがアクセスする Google ユーザーデータ

Google ログイン方式を使う場合、本プラグインは次の権限（スコープ）だけを求めます。

  • https://www.googleapis.com/auth/youtube.readonly（YouTube アカウントの表示・読み取り専用）

この権限を使って、YouTube Data API からログインしたチャンネル自身のライブ配信の一覧（配信中・配信予定の枠の動画 ID、開始時刻など）を読み取ります。動画やコメントの投稿・変更・削除など、書き込みは一切行いません。

2. 利用目的

読み取った情報は、配信中（または開始予定が近い）枠の動画 ID を見つけ、利用者の PC で動いているわんコメの YouTube 枠の URL を書き換えるためだけに使います。それ以外の目的（広告、分析、学習データなど）には使いません。

3. 保存する情報

次の情報を、利用者の PC の中（%APPDATA%\onecomme\plugins\yt-live-autoset\state.json）にだけ保存します。

  • 設定画面で入力した値（OAuth クライアント ID・シークレット、API キー、チャンネル、確認間隔など）
  • Google ログインで得たリフレッシュトークン

これらは暗号化されずに保存されます。ファイルを他人に渡したり、共有フォルダに置いたりしないでください。YouTube から読み取った配信の情報は、処理のために一時的にメモリ上で使うだけで、ファイルには保存しません。

4. 第三者への提供・送信

本プラグインは、Google ユーザーデータを含む利用者の情報を、作者や第三者に送信・提供・販売しません。通信先は次のとおりです。

通信先目的
www.googleapis.comYouTube Data API（配信中の枠を探す）
oauth2.googleapis.com / accounts.google.comGoogle ログイン、トークンの更新・取り消し
127.0.0.1（利用者の PC 自身）わんコメ本体の API（枠の URL の書き換え）、ログイン時の戻り先

5. Google API サービスのユーザーデータに関するポリシー

本プラグインによる Google API から受け取った情報の使用および他のアプリへの転送は、限定使用の要件を含む Google API サービスのユーザーデータに関するポリシーに準拠します。

6. YouTube API サービスについて

本プラグインは YouTube API サービスを使用します。本プラグインを使用することで、YouTube 利用規約に同意したものとみなされます。Google による情報の扱いについては Google プライバシー ポリシーをご覧ください。

7. アクセス権の取り消しとデータの削除

  • 設定画面の「ログアウト」を押すと、保存したトークンを削除し、Google 側の許可も取り消します
  • Google アカウントの「サードパーティ製のアプリとサービス」からも、いつでも許可を取り消せます
  • わんコメでプラグインを無効にし、%APPDATA%\onecomme\plugins\yt-live-autoset フォルダを削除すると、本プラグインが保存したすべての情報が消えます

8. このポリシーの変更

このポリシーを変更する場合は、このページで内容と日付を更新してお知らせします。

9. お問い合わせ

本ポリシーについてのお問い合わせは、GitHub の Issues へお願いします。
