配信枠オートセット（わんコメ用プラグイン・非公式）

うまく動かないときは、まず下の「よくある質問」をご覧ください。解決しないときは、ページ下の送り先から送ってください。

このプラグインは非公式です。わんコメ・YouTube・Google の各社には問い合わせないでください。

よくある質問

インストール・設定画面

設定画面を開くと「Notfound plugin」と出る

わんコメがプラグインを読み込めていません。次を確認してください。

  • わんコメの「プラグイン」画面 →「プラグインフォルダ」を開き、その中に yt-live-autoset フォルダがあり、さらにその中に plugin.js があるか。
    yt-live-autoset-0.5.1 のような外側のフォルダごと入れてしまうと読み込まれません
  • フォルダを入れたあと、プラグイン画面の「再読み込み」を押したか
  • プラグイン一覧でこのプラグインが有効になっているか

設定画面は、プラグイン一覧に出ている URL をクリックして開くのが確実です。

新しいバージョンに更新したい

配布されている zip の中の yt-live-autoset フォルダで、プラグインフォルダの中の同じ名前のフォルダを上書きし、「再読み込み」を押してください。設定やログインはそのまま残ります。

Google ログイン

ログインすると「アクセスをブロック」「エラー 403: access_denied」と出る

Google Cloud の「OAuth 同意画面」が「テスト中」のままになっています。次のどちらかをしてください。

  • 「対象」のページで「アプリを公開」を押し、「本番環境」にする（おすすめ）
  • または、「テストユーザー」に自分の Google アカウントを追加する（7 日ごとにログインし直しになります）

手順は 説明書の「準備 2-A」にあります。

「アプリを公開」が押せない

Google Cloud の「ブランディング」で、ホームページとプライバシーポリシーの URL を入れて「保存」してください。入れる URL は説明書の「準備 2-A」に書いてあります。

「このアプリは Google で確認されていません」と出る

自分で作った Google Cloud のアプリなので、この画面が出るのは正常です。「詳細」→「（アプリ名）（安全ではないページ）に移動」と進んでください。ここで使うのは、あなた自身が作ったアプリです。

「Google のログインが切れました」と出る

OAuth 同意画面が「本番環境」になっているか確認してから、設定画面でもう一度「Google でログイン」を押してください。「テスト中」のまま使っていると、7 日ごとにログインが切れます。

配信が見つからない・接続されない

「待機中」のまま、配信が見つからない
  • API キー方式の場合、見つけられるのは公開の配信だけです。限定公開・メンバー限定の配信は、Google ログイン方式にしてください
  • 予約枠は、開始予定の 24 時間前になるまでセットされません
  • API キー方式の場合、設定画面の「チャンネル」が配信しているチャンネルになっているか確認してください。Google ログイン方式の場合は、配信しているチャンネルの Google アカウントでログインしているか確認してください
URL はセットされたのに、コメントが流れない
  • わんコメの枠の接続を、一度オフにしてからオンにしてみてください
  • 「チャットは現在ご利用いただけません」と出る場合は、配信が非公開になっていないか確認してください。非公開の配信は YouTube 側でチャットが使えません。「今すぐ配信」は前回の公開設定を引き継ぐことがあります
  • 設定画面の「配信が始まったら、わんコメの接続を自動でオン（つなぎ直し）にする」にチェックが入っているか確認してください
予約枠で配信を始めたのに、自動で接続されなかった

0.4.0 以前のバージョンでは、予約枠をあらかじめセットしていた場合に、配信開始時に接続されないことがありました。0.4.1 以降で直っているので、最新版に更新してください。

「YouTube の枠ではないため書き換えません」と出る

設定画面の「書き換えるわんコメの枠」に、ツイキャスなど YouTube 以外の枠を選んでいます。YouTube の枠を選び直してください。

そのほかのエラー

「API キーが正しくありません」と出る

API キーのコピーミスがないか、Google Cloud でキーに「API の制限」をかけている場合は YouTube Data API v3 が許可されているかを確認してください。

「YouTube Data API v3 が有効になっていません」と出る

Google Cloud のプロジェクトで「YouTube Data API v3」を有効にしてください（説明書の「準備 1」）。

「1 日の利用上限に達しました」と出る

設定画面で「確認する間隔（秒）」を長くしてください。上限は毎日リセットされます（日本時間の 16 時〜17 時ごろ）。

解決しないとき（不具合・質問の送り先）

送るときに書いてほしいこと

  • どうなったか（画面に出たメッセージはそのまま）
  • いつ起きたか（日時・配信枠が予約枠かどうか）
  • プラグインのバージョン（プラグイン一覧に出ています）とわんコメのバージョン

API キー・クライアント シークレット・メールアドレスは送らないでください。スクリーンショットを送るときも、これらが写っていないか確認してください。

不具合・質問フォーム（おすすめ）
アカウントがなくても送れます。返事がほしい場合は、フォームの「返信先」に X の ID などを書いてください。

フォームを開く

フォームは Google フォームを使っています。送られた内容は、返信と不具合の修正にだけ使い、ほかの人には渡しません。

BOOTH のメッセージ
BOOTH のショップページの下にある「ショップへのお問い合わせ」からも送れます（pixiv のアカウントでログインが必要です）。

GitHub に慣れている方は、GitHub の Issues でも受け付けています。

個人で作っているため、返信に数日かかることがあります。
