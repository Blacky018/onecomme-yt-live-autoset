## 商品説明（ここから下を貼る）

---

YouTube で配信を始めると、わんコメの YouTube 枠の URL を「今配信している枠」に自動で書き換える、わんコメ用のプラグインです。
配信のたびに URL をコピーして貼り替える手間がなくなります。

※ 非公式のプラグインです。わんコメ（OneComme）・YouTube・Google とは関係ありません。各社へのお問い合わせはご遠慮ください。

■ できること
・自分のチャンネルの配信中の枠を 30 秒おき（変更可）に探し、わんコメの YouTube 枠にセットします
・配信前でも、開始予定が近い予約枠（24 時間前から）を先にセットし、わんコメの接続をオンにします。待機所のコメントも取れます
・配信が始まったら、わんコメの接続を自動でオン（つなぎ直し）にします
・Google ログイン方式なら、限定公開・メンバー限定の配信も見つけられます
・YouTube 以外（ツイキャスなど）の枠は書き換えません

■ 動作環境
・わんコメ 5.2 以上（Windows）
・Google アカウント（配信しているチャンネルのもの）
・Google Cloud のプロジェクト（無料。作り方は説明書にあります）
　YouTube Data API を使うため、利用者ご自身で API の準備が必要です（10〜15 分ほど）

■ 使い方
1. zip を展開し、中の「yt-live-autoset」フォルダを、わんコメの「プラグイン」画面 →「プラグインフォルダ」に入れます
2. 「再読み込み」を押して、プラグインを有効にします
3. プラグイン一覧の URL をクリックして設定画面を開き、Google ログイン（または API キー）と、書き換えるわんコメの枠を設定します
詳しい手順（Google Cloud の準備など）は、設定マニュアルをご覧ください。
https://blacky018.github.io/onecomme-yt-live-autoset/manual.html

■ 更新するとき
新しい「yt-live-autoset」フォルダで上書きし、「再読み込み」を押してください。設定はそのまま残ります。

■ わんコメのクレジット表記について
このプラグインは、わんコメの HTTP API を使います。わんコメを無料版として使っている場合は、配信の概要欄などに、わんコメを使っていることのクレジットを書いてください（わんコメの利用規約「クレジット表記について」）。
記載例: 配信者のためのコメントアプリ「わんコメ」https://onecomme.com
・FANBOX でわんコメを支援している場合は任意です
・概要欄などの入力欄がない場合や、文字数制限が厳しい場合は書かなくてかまいません
