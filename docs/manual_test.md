# 実機の確認リスト（本物のわんコメ・YouTube）

自動の E2E（`npm run test:e2e`）は、わんコメ・YouTube・Google を偽物にして通しで確かめる。
ここには、偽物では確かめられないこと（本物の画面・本物の配信・わんコメ本体の動き）を書く。
リリース前に、変更に関係する項目を確認する。結果は日付付きで残す。

## 準備

- [ ] 配布用 zip（`npm run package`）を展開し、README の手順だけでインストールできる
- [ ] わんコメの「プラグイン」画面に「配信枠オートセット（非公式）」・作者「りーと」・バージョンが出る
- [ ] 設定画面（`http://localhost:11180/plugins/com.riito.yt-live-autoset/index.html`）が開く
- [ ] 書き換える枠の一覧に、わんコメの枠が出る

## Google ログイン方式

- [ ] 「Google でログイン」→ 同意 →「ログインしました」→ 設定画面が「ログイン済み」
- [ ] 限定公開の配信が見つかり、コメントが流れる
- [ ] メン限の配信が見つかり、コメントが流れる（未確認）
- [ ] 「ログアウト」で Google アカウントの「サードパーティ製のアプリとサービス」から消える

## API キー方式

- [ ] 公開の配信が見つかり、コメントが流れる

## 予約枠と配信開始

- [ ] 予約枠を作ると、配信前に URL が先にセットされる（待機所のコメントが流れる）
- [ ] 予約枠で配信を始めると「配信が始まったので、接続をつなぎ直しました」と出て、コメントが流れる
- [ ] つなぎ直しの前後でコメントが抜けない・二重にならない
- [ ] 予約枠をセット・接続オンのままわんコメを閉じ、翌日起動して配信 → 接続される（11/02 のケース）
- [ ] 接続オフのまま「今すぐ配信」→ 1 分以内に接続される
- [ ] 配信中に手動で接続をオフにすると、そのまま（勝手にオンに戻らない）

## 更新
